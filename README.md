# Perio Recovery

A simple phone web app that turns a periodontist's post-op instruction sheet into a daily checklist and reminders for the 2 weeks after gum graft surgery.

- Everything a patient enters stays on their own phone (browser storage). Nothing is sent to a server.
- Settings live in the `CONFIG` object at the top of the script in `index.html` (practice details, medicine timing, rinse days, graft brushing day, survey link).
- Add `#preview` to the address to test any day from 0 to 14.

This is a pilot. The paper instruction sheet remains the official guidance.
